# Documentation

Comprehensive documentation that teaches Platform Engineering concepts — not just describes files.

## Documents

| Document | Purpose | Target Audience |
|----------|---------|-----------------|
| `architecture.md` | Platform architecture with diagrams and component interaction | Everyone |
| `decisions.md` | Architectural Decision Records (ADRs) with rationale | Architects, interviewers |
| `repository.md` | Directory-by-directory explanation of why each folder exists | Contributors |
| `deployment.md` | Step-by-step deployment and configuration guide | Operators |
| `walkthrough.md` | End-to-end Golden Path demo from developer push to production | Developers |
| `demo.md` | 15-minute live demo script for portfolio presentations | Presenters |
| `interview.md` | Common Platform Engineering interview Q&A mapped to this project | You |
| `troubleshooting.md` | Common issues and diagnostic commands | Operations |

## Philosophy

Documentation is a product feature, not a chore. Good docs reduce onboarding time from weeks to hours. Each document targets a specific persona with a specific goal.
